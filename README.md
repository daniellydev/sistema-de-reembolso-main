# Sistema de Reembolso

Projeto de um sistema para cadastro e acompanhamento de solicitações de reembolso, desenvolvido com HTML, CSS e JavaScript.

A aplicação permite informar os dados de uma despesa, selecionar sua categoria, adicionar o valor e acompanhar as solicitações cadastradas.

## Funcionalidades

- Adicionar novas despesas
- Informar o nome da despesa
- Selecionar a categoria da despesa
- Informar o valor do reembolso
- Exibir a quantidade de despesas cadastradas
- Exibir o valor total das despesas
- Atualizar as informações da tela de forma dinâmica

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
